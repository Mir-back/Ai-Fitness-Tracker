# Forme Fitness

Учебный проект для промежуточного экзамена по Programming Language: фитнес‑трекер с журналом тренировок и персональными рекомендациями.

## Запуск сервера

Нужен Node.js 18 или новее. Зависимости устанавливать не требуется.

**Windows:** откройте PowerShell в папке проекта и запустите:

```powershell
.\start.ps1
```

**macOS / Linux:**

```sh
./start.sh
```

Затем откройте <http://localhost:4173/>. Сервер сохраняет аккаунты и тренировки в локальный файл `data/fitness-data.json`, который не попадает в Git. Остановить сервер можно сочетанием `Ctrl+C`.

## Что умеет приложение

- регистрация и вход с хешированием пароля на сервере;
- создание профиля с целью тренировок, опытом, доступным оборудованием и планом на неделю;
- добавление и удаление занятий с видом активности, продолжительностью, субъективной нагрузкой и заметкой;
- статистика, недельный график активности, история и серия тренировочных дней;
- персональные рекомендации, сформированные сервером по профилю и истории активности;
- адаптивная вёрстка, мобильная навигация и демонстрационный режим.

Рекомендации проекта строятся на прозрачных правилах по введённым данным и истории тренировок; это учебный прототип AI‑подхода, не медицинская рекомендация. Не вводите чувствительные медицинские сведения.

## Публикация

Workflow GitHub Pages публикует статический интерфейс после push в `main`. На GitHub Pages работает браузерный демо‑режим с сохранением в `localStorage`. GitHub Pages не запускает Node.js API: для аккаунтов и хранения данных на сервере запустите проект командой выше или разверните `server.mjs` на Node.js‑хостинге.

## Структура

- `index.html` — интерфейс приложения;
- `styles.css` — адаптивный дизайн;
- `app.js` — навигация, формы, журнал и клиентская работа с API;
- `server.mjs` — HTTP‑сервер и REST API;
- `TZ.md` — техническое задание проекта.
